# Build Pipeline Guide

## Overview

This repository uses an automated pipeline to build smart contracts in TypeScript and generate corresponding Dart bindings automatically.

## Architecture

```
┌─────────────────────────────────────┐
│  Solidity Contracts                 │
│  (packages/typescript/              │
│   signaling-contract/contracts/)    │
└────────────────┬────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────┐
│  Hardhat Compile                    │
│  → Generates ABI & Bytecode         │
│  → Creates JSON Artifacts           │
└────────────────┬────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────┐
│  TypeChain Generation               │
│  → TypeScript Types for TypeScript   │
│  → Placed in signaling-sdk/         │
└────────────────┬────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────┐
│  Dart Binding Generation            │
│  → Read Contract ABI                │
│  → Generate Dart Classes            │
│  → Place in contract_sdk/lib/       │
│  → Generate exports file            │
└────────────────┬────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────┐
│  Validation                         │
│  → Verify all bindings exist        │
│  → Check integrity                  │
│  → Report errors                    │
└─────────────────────────────────────┘
```

## Local Development

### Setup

```bash
# One-time setup
melos run dev:setup

# Or manually:
cd packages/typescript/signaling-contract
npm install

cd ../../contract_sdk
dart pub get
```

### Building

#### Option 1: Full Build (Recommended)
Build contracts AND automatically generate Dart types:

```bash
melos run contracts:build
```

#### Option 2: Build Only Contracts
Compile contracts and generate TypeChain types (no Dart):

```bash
melos run contracts:build:typechain
```

#### Option 3: Generate Only Dart
Regenerate Dart bindings from existing artifacts:

```bash
melos run contracts:build:dart
```

### Development Workflow

**When you modify a Solidity contract:**

```bash
# Build contracts and regenerate all types
melos run contracts:build

# Or use individual commands:
cd packages/typescript/signaling-contract
npm run build:contracts      # Compile contracts
npm run build:dart          # Generate Dart types
npm run validate            # Verify everything
```

**When you modify multiple files:**

```bash
# Full pipeline
npm run build
```

### Cleanup

```bash
# Clean all build artifacts
melos run clean
```

## Scripts Reference

### Melos Scripts (Run from root)

- `melos run contracts:build` - Full build + Dart generation
- `melos run contracts:build:typechain` - TypeScript types only
- `melos run contracts:build:dart` - Dart types only
- `melos run dev:setup` - Initial development setup
- `melos run analyze` - Analyze all Dart packages
- `melos run test` - Run all tests
- `melos run format` - Format code
- `melos run clean` - Clean build artifacts

### NPM Scripts (Run from `packages/typescript/signaling-contract`)

- `npm run build` - Full build: contracts + typechain + dart + validate
- `npm run build:contracts` - Hardhat compile + typechain
- `npm run build:typechain` - TypeChain generation
- `npm run build:dart` - Dart binding generation
- `npm run validate` - Validate generated bindings
- `npm run deploySC` - Deploy to localhost
- `npm run deploySC:ganache` - Deploy to Ganache
- `npm run network` - Start local Hardhat node
- `npm run clean` - Clean generated files

## CI/CD Pipeline

The repository includes GitHub Actions workflows that automatically:

1. **Trigger on**: 
   - Push to `main` or `develop` branches
   - Changes to contract files or configuration
   - Pull requests affecting contracts

2. **Actions**:
   - Install dependencies (Node + Dart)
   - Build contracts
   - Generate Dart bindings
   - Validate all generated types
   - Run analysis on generated code
   - Create PR if changes detected (for push events)

3. **View Status**:
   - Go to `.github/workflows/build-contracts.yml`
   - Check GitHub Actions tab in the repository

## Generated Files

### TypeScript Types
- Location: `packages/typescript/signaling-sdk/src/typeschain/`
- Generated by: Hardhat TypeChain plugin
- Updated when: Contracts compile

### Dart Bindings
- Location: `packages/contract_sdk/lib/generated/`
- Files:
  - `contracts.dart` - Main export file
  - `*_contract.dart` - Individual contract bindings
- Generated by: `scripts/generate-dart-bindings.js`
- Updated when: `npm run build:dart` is executed

## Troubleshooting

### Bindings out of sync
```bash
# Regenerate all bindings
melos run contracts:build

# Or force regeneration:
cd packages/typescript/signaling-contract
npm run build
```

### TypeScript compilation errors
```bash
# Clear cache and rebuild
cd packages/typescript/signaling-contract
npm run clean
npm install
npm run build
```

### Dart analysis errors
```bash
# Update dependencies and reanalyze
cd packages/contract_sdk
dart pub get
dart analyze
```

### Full reset
```bash
# Clean everything and rebuild
melos run clean
melos run dev:setup
```

## Adding New Contracts

1. Create `.sol` file in `packages/typescript/signaling-contract/contracts/`
2. Run full build:
   ```bash
   melos run contracts:build
   ```
3. Dart bindings will automatically be generated
4. Commit both TypeScript and Dart changes

## Best Practices

✅ **DO:**
- Always run full build after modifying contracts
- Run validation after generating bindings
- Commit both TypeScript and Dart generated files
- Use melos scripts for consistency

❌ **DON'T:**
- Manually edit generated `.dart` files
- Modify TypeChain generated TypeScript
- Run builds from different directories inconsistently
- Skip validation after contract changes
